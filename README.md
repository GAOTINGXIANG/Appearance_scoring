AI 颜值评分系统

一、项目概述

本项目是一款基于计算机视觉与人脸特征点检测技术的颜值评分工具，通过分析人脸的七个子维度对颜值进行综合打分，满分100分。同时支持调用OpenAI兼容API进行AI辅助评分。

二、技术架构

人脸检测层使用OpenCV的Haar级联分类器快速定位人脸区域。特征提取层采用Google的MediaPipe FaceLandmarker模型，检测478个人脸关键特征点，涵盖眼睛、眉毛、鼻子、嘴唇、下巴、轮廓等部位的几何信息。评分算法层使用高斯平滑曲线和指数衰减替代传统的硬阈值判断，避免在极端输入时出现分数突然归零的现象。AI能力层通过OpenAI兼容SDK实现，支持 Vision 多模态图片输入，可以对指定人脸图片进行AI点评。界面层使用Tkinter构建，包含主检测窗口和AI对话子窗口。

三、评分维度

本系统从七个维度综合评估人脸颜值。

对称性满分25分，通过计算人脸关键特征点与其镜像点的欧氏距离偏差来评估，距离越小分数越高。

皮肤质量满分25分，基于YCrCb色彩空间分析肤色均匀度和皮肤覆盖率，方差越小肤色越均匀。

面部比例满分20分，综合评估面型宽高比是否符合黄金比例、三庭比例是否均衡、眼距比例和嘴宽比例是否标准。

眼睛有神满分10分，通过眼高与眼宽的比值来衡量眼睑开合程度，数值在0.28到0.48之间为最佳。

嘴唇饱满满分10分，以唇高与唇宽的比值作为评估标准，采用高斯平滑曲线计算，即使在嘴唇闭合状态下也不会归零。

下巴轮廓满分5分，评估下巴高度占下庭总高度的比例是否适中。

眉眼协调满分5分，综合考虑眉眼距离与眼高的比例以及左右眉高度差，通过加权方式合成最终分数。

四、项目结构

face_gui.py是程序入口文件，负责启动图形界面。config.py集中管理所有评分标签、模型路径、窗口参数等常量配置。face_detector.py是核心模块，实现人脸检测、特征点提取和七维度评分算法。ai_client.py封装了OpenAI兼容SDK的调用逻辑，支持文本对话和带图片的多模态对话。utils.py提供评分标签映射、颜色选择、图像读写等公共工具函数，对中文文件路径做了专门处理。gui_main.py构建主窗口界面，实现图片加载、摄像头检测、结果显示和保存功能。gui_ai_window.py构建AI评分子窗口，提供API配置入口和对话历史管理。

五、主要特性

本系统支持单张图片加载和摄像头实时检测两种输入方式。检测结果会在图片上直观标注各维度得分和特征数值，并支持结果图片保存。评分曲线采用平滑过渡设计，避免硬阈值造成的分数突变。针对嘴巴闭合、严重不对称等极端情况设置了保底分数，确保不会给出零分。AI评分功能可对接任意OpenAI兼容接口，支持发送图片给AI获取专业点评。程序对中文文件路径有良好支持。
